# 对话模式推演引导（不用命令行，纯聊天完成一次完整推演）

> 目标用户：不懂命令行的小老板 / 创业者。高级用户请直接用 README「方式 B：只用命令行」。

## 一句话开始

你只需要对 AI 说一句你真实的想法，比如：

> "我想在我们县开一个社区团购自提点，帮我倒推一下这事能不能干、要办什么证、最可能死在哪。"

技能被触发后，它会自动走完四阶段，你全程只用聊天回答问题就行。

## 四阶段你会经历什么（对话视角）

| 阶段 | 它会对你说 | 你要做的 |
|---|---|---|
| ① 目标锁定 | "先确认：你要达到的结果是 XX，对吗？"（给选项） | 选一个 / 打字纠正 |
| ② 硬性条件 | "做这事必须先有：A 证照、B 资金、C 资源，你已有哪些？" | 逐条回答有 / 没有 |
| ③ 倒排里程碑 | "从今天到开业，倒排是：第 1 周必须先交 XX 材料……" | 看有没有做不到的，说出来 |
| ④ 沉淀复用 | "本次推演发现 2 条新踩坑，已入待审区" | 无需操作 |

## 你会说的话术速查（全部可选，不会说就跳过）

- **换行业**：直接说真实行业，如"不是团购，是做家政中介"
- **要更快**：说"少问点，直接给结论"（红线照常召回，但报告简化）
- **要更细**：说"把办证清单展开，每一项告诉我去哪个部门、带什么材料"
- **怕违规**：说"帮我查一下 XX 这条路会不会踩红线"
- **已经做了一半**：说"我已经办了营业执照和 XX，剩下的倒推一下"

## 推演完成后你会拿到什么

一份结构化报告，固定包含：**合规红线清单（带编码）+ 资源底线（钱/人/时间）+ 致命风险点（最可能死在哪）+ 倒排周计划 + 免责声明**。把报告截图保存即可，AI 侧的知识库已自动沉淀本次踩坑。

## 三个诚实提醒

1. 报告是**经验推演，不是法律意见**——办证前一定去官方渠道核实（报告每条红线都附了核实入口）；
2. 超 90 天未核实的法规规则会自动标注"可能过时"，看到 ⚠ 标记优先核实；
3. 知识库沉淀在你本机，不上传不共享，你的商业想法不会外泄。
