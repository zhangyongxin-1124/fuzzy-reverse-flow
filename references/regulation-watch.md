# 法规规则观察清单与人工快更流程（v1.4.0）

> 背景：法规与平台规则变动快，知识库里的法规类规则（`category` 或 `tags` 含 `法规` / `监管` / `regulation`）若滞后，会误导用户。`rfe doctor` 已内置短周期提醒（`RFE-DR-103`：法规类规则超 90 天未核实即告警，早于普通规则的 91-180 天季度复核），本文件配套提供**订阅提醒 + 人工快更**的操作流程。

## 一、权威信息源清单（订阅建议）

> 原则：只认官方一手渠道；自媒体与第三方解读只作线索，不作核实依据。

| 领域 | 信息源 | 关注内容 |
|---|---|---|
| 企业与营业执照 | 国家企业信用信息公示系统、当地市场监管局官网/窗口 | 经营范围、许可前置 |
| 食品/餐饮 | 市场监管总局《食品经营许可管理办法》及地方细则 | 食品经营许可证、健康证 |
| 互联网应用 | 工信部 ICP/App 备案系统、全国互联网安全管理服务平台（公安备案） | App 备案、算法备案 |
| 软件与著作权 | 中国版权保护中心 | 软件著作权登记要求与周期 |
| 内容与出版 | 国家新闻出版署、国家广播电视总局 | 网络出版、节目类目资质 |
| 支付与资金 | 中国人民银行、非银行支付机构监管规定 | 支付牌照、预付资金监管 |
| 招聘/人力资源 | 人力资源社会保障部（人力资源服务许可） | 劳务派遣、人力资源服务备案 |
| 应用商店规则 | 微信小程序平台运营规范、各安卓商店提审规范 | 类目资质、审核口径变动 |
| 广告与宣传 | 《广告法》及市场监管总局执法指引 | 极限词、虚构原价、代言边界 |
| 个人信息 | 《个人信息保护法》《网络安全法》配套细则与国家标准 | 隐私政策、收集最小化 |

## 二、人工快更流程（收到 RFE-DR-103 后执行）

1. **定位**：`rfe doctor` 列出超期法规规则 ID（`[RFE-DR-103]` 行）。
2. **核实**：逐条打开上表对应官方源，确认该规则所述要求是否仍然有效、是否已变。
3. **更新**：
   - 仍有效 → `rfe verify --id <ID> --confidence high`（刷新核实时间戳）；
   - 已变化 → `rfe add rule ...` 写入新规则，旧的执行 `rfe meta --set deprecated`（废止条目保留、召回时提示勿再引用）；
   - 无官方依据 → 直接废止，并在 `guard` 说明驳回原因。
4. **留痕**：快更完成后重跑 `rfe doctor`，确认 `RFE-DR-103` 清零；把本次变更记入 CHANGELOG 或工作日志。
5. **预防**：每季度初把上表各官方源浏览一遍（约 30 分钟），新规在生效前提前入库，等 `RFE-DR-103` 提醒已是兜底而非首选。

## 三、与自动提醒的分工

| 机制 | 触发方式 | 覆盖 |
|---|---|---|
| `RFE-DR-103`（本仓库 doctor） | 每次跑 doctor 自动比对 90 天阈值 | 法规类规则的**时限**兜底 |
| 人工订阅浏览（本清单） | 每季度 + 重大政策节点主动看 | 法规内容的**及时性**主线 |

> 免责：本清单为经验性导航，不构成法律意见；任何规则入库前必须附官方原文链接或窗口核实记录。
