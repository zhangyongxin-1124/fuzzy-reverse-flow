# 阶段一：目标锁定（Target Locking）

> 目的不是"了解用户想要什么"，而是**拆掉他用错的那个词**。
> 用户说"我要做个 App"，十次里有七次，App 不是目标，是手段。

---

## 1. 为什么必须锁定

逆向推演的精度取决于目标的精度。目标偏 1 度，倒排出来的路径会偏 1 公里：
- 把"做个电商平台"当目标 → 反推出 EDI、支付、招商、抽成体系（周期 9 个月）
- 真实目标是"验证 40+ 人群愿不愿意为找工作付 9.9 元" → 反推出 1 个落地页 + 50 个真实岗位 + 2 周

**锁定阶段唯一产出：一句可以拿去做验收的真目标。**

---

## 2. 八维选项库（每维给猜测 + 选项，不要让用户从零回答）

### 2.1 目标（最终结果）
| 选项 | 特征 | 反推方向 |
|---|---|---|
| A 可运营的业务 | 有付费、有留存、要持续维护 | 全量合规 + 组织 + 现金流 |
| B 可验证的原型 | 只验证一个假设 | 最小合规（可不上架） |
| C 可融资的资产 | 要讲增长故事 | 数据、团队、资质完备度 |
| D 一次性交付物 | 项目制、交付即结束 | 验收标准 + 版权归属 |

追问话术：*"如果这个 App 上线了但没人用，你会觉得失败吗？"* → 回答"会"说明目标是业务；"不会，我只是想看看能不能做"说明是原型。

### 2.2 对象（具体部分）
必须切出"要做的那一段"：全平台 / 只做一侧（求职端、商家端）/ 只做一条链路（撮合、支付、履约）/ 只做某个地区。

追问：*"第一版里，哪三个功能是绝对不能没有的？哪三个可以先砍？"*

### 2.3 受众（三套受众，别混）
| 受众 | 决定什么 |
|---|---|
| 使用者 | 交互、适老化、语音输入 |
| 付费者 | 商业模式、定价、发票 |
| 审核者（监管/平台/应用商店） | 资质、类目、文案红线 |

追问：*"谁掏钱？"* 若答不出 → 标记"商业假设未验证"，阶段二自动降级为最小验证版。

### 2.4 范围（含 / 不含，写死）
用"包含 / 不包含"两列写死，尤其是这几个高危开关：
- 有没有 UGC（用户发内容）→ 触发内容审核义务
- 有没有交易（收钱）→ 触发经营性与支付合规
- 有没有直播 → 触发视听/网络文化类要求
- 有没有跨境 → 触发数据出境与海关
- 有没有未成年人 → 触发未成年人保护义务

### 2.5 约束
时间（硬截止日是什么？）、预算（含不含资质与合规？）、人力（有没有能拍板的人？）、技术（自有/外包/贴牌）。

**关键提醒**：预算必须区分"开发预算"与"合规预算"。10 万元预算里若没有 2–4 万元的资质与合规预留，方案必然在中途断粮。

### 2.6 标准（怎么算成功）
必须是可量化、可验收、可拍板的句子。反面例子："上线运行"；正面例子："上线 30 天内完成 100 笔真实支付订单，退款率 < 5%"。

### 2.7 优先级（只能保一个）
强制排序四选一：**合规 > 速度 > 成本 > 体验**（默认按此序，用户可改）。
一旦选定，后续冲突一律按此裁决，不再反复讨论。

### 2.8 输出形式
方案 / 倒排任务书 / 代码 / 清单 / 预算表 / 汇报材料。默认给"方案 + 倒排任务书 + 规则卡"三件套。

## 3. 伪需求四问（命中任一即先纠偏）

1. **手段当目标**：用户给的是名词（App、小程序、网站、IP），不是结果。追问"你要它替你完成什么"。
2. **没有付费方**：使用者与付费者都指向"所有人" → 等于没有付费方。
3. **法律或物理不可能**：个人主体做资金池、无资质做诊疗、无授权改编他人 IP。→ 直接红灯 + 给合规替代形态。
4. **量级错配**：预算与目标差一个数量级（10 万做多商户平台）。→ 给 A/B/C 三档方案，让用户选档位而不是选要不要。

> 纠偏不是否定用户，而是把"不可能"换成"这个预算下的可行形态"。

---

## 4. 阶段一自检（5 条全过才进入阶段二）

- [ ] 真目标能用一句话说清，且不含"平台/系统/App"这类手段词
- [ ] 三个高危开关（UGC / 交易 / 直播）已明确置为"含"或"不含"
- [ ] 每个未确认维度都写了"默认假设 + 若相反则……"
- [ ] 优先级已排序（合规/速度/成本/体验）
- [ ] 成败标准可量化

---

## 5. 输出样例

```
【阶段一 · 目标锁定】
真目标：让 40+ 求职者在 3 个月内完成 500 次真实面试，并向企业侧收费。
默认假设：
  1) 不做在线支付（若要做 → 增加支付与资金合规 3 周）
  2) 不做培训（若要做 → 触发教育培训资质）
  3) 首发只做杭州（若全国 → 各地人社口径差异需另行核实）
八维表：见表
伪需求体检：命中第 2 条（付费方模糊）→ 纠偏为"向企业收费，永不向求职者收费"
待拍板：① 是否接受"不做在线支付" ② 首发城市 ③ 是否接受 3 名专职人员的社保成本
```
